All daily customer details, self-service orders, and bills are automatically stored in the built-in Real-Time Cloud NoSQL Database (`dailyCustomers` collection). You can also connect an external Cloudflare Worker + D1 SQL / KV / Supabase REST URL below to mirror every customer record in real time.

1 Create GitHub Repository

Click "Download index.html for GitHub" above. Go to github.com/new, create a repository (e.g., grand-horizon-hotel), and upload index.html.

2 Go Live (GitHub / Cloudflare Pages)

In your GitHub repo, open Settings → Pages, set Branch to main and click Save (or connect the repo to Cloudflare Pages). Your live URL will be ready in 60 seconds!

3 Push Future Updates Instantly

Whenever you edit index.html, run git add . && git commit -m "update" && git push (or edit directly on GitHub) and your live website updates automatically.
